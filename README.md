# xenzen2D
2D sidescroller/platformer game for PC, no details yet.....
**Engine:** Godot  
**Language:** GDScript (Python-like) or C# optional  
**Goal:** 2D sidescroller/platformer; export to Windows `.exe`

## Quick start
1. Install Godot and VS Code.
2. Clone repo: `git clone <repo-url>`
3. Install Git LFS: `git lfs install`
4. Pull LFS assets: `git lfs pull`

## Project structure
- `/project` → Godot project files
- `/docs` → design docs
- `/tools` → helper scripts
